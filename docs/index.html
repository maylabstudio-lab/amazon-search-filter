Amazon Search Filter

プライバシーポリシー

最終更新日: 2026年9月16日

収集する情報

Amazon Search Filter は、個人情報、検索キーワード、閲覧履歴、商品情報を開発者のサーバーへ 収集・送信しません。外部サーバーとの通信は一切行いません。

ローカル保存

本拡張機能は、ポップアップまたはページ内パネルで選択した設定（「正規品に絞る」、正規品ワードの付加、 カテゴリ、発送元・直販・割引率、パネルの表示可否）を chrome.storage.sync に保存します。 パネルの開閉状態は各サイトの localStorage に保存します。いずれもお使いの端末および Google アカウントに同期される Chrome 内のみで、開発者や第三者へ送信されることはありません。 検索キーワードは保存しません。

保存した設定は、Chrome の拡張機能管理画面から本拡張機能を削除すると消去されます。

Amazon.co.jp ページ内での動作

本拡張機能は https://www.amazon.co.jp/ 配下のページで動作し、次の処理をページ内で行います。 いずれも商品情報の収集・保存・外部送信は行いません。

  • 折りたためる操作パネルを表示します（ポップアップの設定でオフにできます）。
  • 検索結果ページ（/s）では、表示されている商品タイトルの文字列を、あらかじめ拡張機能内に持つ 禁止ワードの一覧および商品名規約の判定ルールと照合し、規約外と判定した出品を非表示または注意ラベル表示にします。

Amazon アソシエイト・プログラム

本拡張機能は Amazon アソシエイト・プログラムの参加者です。ポップアップまたはページ内パネルの 検索欄からユーザー自身が検索を実行したときに生成する検索 URL に、アソシエイトタグ（tag パラメータ）を付与します。既存のページや自動で開くリンクへタグを差し込むことはありません。この タグを経由して Amazon.co.jp で買い物をされた場合、Amazon の紹介プログラムにより開発者が紹介料を 得ることがあります。ユーザーの支払い金額が変わることはありません。

任意の支援

開発者への任意の支援を選択した場合、外部の支援サービス（Buy Me a Coffee）へ移動します。支援に関する 決済情報を本拡張機能が取得・保存することはありません。支援サービス上のデータ処理については、同サービスの プライバシーポリシーが適用されます。

変更

本ポリシーを変更する場合は、このページと Chrome Web Store の掲載情報を更新します。
