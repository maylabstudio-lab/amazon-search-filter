# Amazon Search Filter

Amazon.co.jpの商品名規約（`[ブランド名] + [商品名] + [仕様・型番・カラー・サイズ]`）に沿わない出品を検索結果で非表示にして、非正規品・模倣品を避けて商品を探しやすくするChrome拡張機能です。Amazonのページには折りたためる操作パネルが常時表示され、拡張機能アイコンを押さずにその場で条件を変えて検索・再検索できます。従来の検索パラメータ（発送元・割引率など）の指定もポップアップから行えます。

## できること

- キーワード検索（ポップアップ / Amazonページ内パネルのどちらからでも）
- 「正規品に絞る」: Amazonの商品名規約（`[ブランド名] + [商品名] + [仕様・型番・カラー・サイズ]`）に沿わない出品を検索結果ページ上で非表示にする（パネルの「すべて表示」で戻せる）。対象は次のいずれか:
  - スーパーコピー・レプリカ・並行輸入などの禁止ワードを商品名に含む
  - 商品名の先頭が「令和最新版」などの宣伝文句、装飾記号（★ 🔥 など）、宣伝的な先頭カッコ（【楽天1位】など）、年号アピール（2024年最新 など）
- チェックを外した場合は非表示にせず、該当出品に注意ラベルを表示
- Amazonのどのページにも表示される操作パネル（ポップアップの設定でオフにできる）
- 「正規品」「国内正規品」および カテゴリ別ワードの検索語への自動付与（任意）
- 「Amazonが発送する商品」フィルターの適用
- `parametor.txt` に定義したAmazon直販商品フィルターの適用
- 10%、20%、30%、40%、50%以上の割引率フィルター
- 選択した条件の保存（`chrome.storage.sync`、外部送信なし）
- 検索結果を新しいタブで開く
- 開発者への任意のコーヒー1杯分の支援

検索URLには、次のAmazonパラメータを使用します。

| GUI項目 | パラメータ | 内容 |
| --- | --- | --- |
| 検索キーワード | `k` | 検索語。「正規品ワードを追加」が有効なときは正規品向けワードを連結（怪しい語の除外は検索結果ページ側で非表示にして行う） |
| Amazonが発送する商品 | `rh=p_6:AN1VRQENFRJNWY` | Amazon発送の商品に絞り込み |
| Amazon直販商品 | `parametor.txt` の定義 | 定義ファイルのパラメータを適用 |
| 割引率 | `pct-off` | 指定した割合以上の割引商品に絞り込み |

## 正規品フィルタ

- 付加ワード・カテゴリ・除外ワードは `dictionary.js` の `GENUINE_DICTIONARY`、商品名規約の
  判定データは `TITLE_POLICY` で定義します。
- 「正規品に絞る」の非表示判定は次の 2 系統です。
  1. `getExcludeWords()` … 商品名に含まれると弾く禁止ワード（共通＋選択カテゴリ）。
  2. `titleViolatesPolicy()` … 商品名の「先頭」だけを見て、`[ブランド名] + [商品名] + [仕様]`
     の形になっていない（先頭が装飾記号・絵文字、宣伝的な先頭カッコ、年号アピール、
     `TITLE_POLICY.leadingPromoPhrases` の宣伝フレーズ）ものを弾きます。
- 除外は Amazon の検索クエリでは行いません。amazon.co.jp は `-キーワード` 構文を安定して
  解釈せず結果が 0 件になることがあるため、`content.js` が結果ページ上で該当出品を
  `display:none` にする方式です（パネルの「すべて表示」で戻せます）。
- 「正規品に絞る」は既定でオン。共通の禁止ワードと商品名規約チェックは常に対象で、
  カテゴリを選ぶとそのカテゴリの禁止ワードが加わります。
- 「正規品ワードを追加」は任意（既定オフ）。オンにすると「正規品 / 国内正規品」とカテゴリの `queries` が検索語に足されます。
- 商品名規約チェックは誤検知を抑えるため商品名の先頭のみを見ます。強すぎる／弱いと感じたら
  `TITLE_POLICY` の各リストを調整してください。
- カテゴリの選択は任意です。「指定なし」でも共通の除外語は効きます。カテゴリは日常的なジャンル（家電・PC・スマホ周辺機器／化粧品・スキンケア／ブランド品・ファッション／時計・アクセサリー／サプリ・健康食品／スポーツ・アウトドア・シューズ／玩具・ホビー・ベビー用品／食品・飲料／日用品・キッチン用品）から選びます。
- 辞書の精度（誤検知・見逃し）は実際の検索結果でのテストを通じて調整していく想定です。
- `content.js` は、AmazonのDOM変更で商品要素が見つからない場合でも例外で止まらず、5秒待っても
  一度も一致しなければコンソールに警告（`[Amazon Search Filter]`）を1回出すだけです。

### パラメータ定義の追加

`parametor.txt` は、パラメータ本体を `&名前=値`、説明を次の行に `--` で記述します。

```text
&emi=AN1VRQENFRJN5
-- amazon直販商品への絞り込み
```

現在はファイル内の最初のパラメータを「Amazon直販商品」に適用します。今後、複数の定義をGUIへ追加する場合は、定義ファイルを項目ごとの構造へ拡張します。

## 導入方法

### 1. ファイルを用意する

このリポジトリをクローンするか、GitHubの「Code」からZIPでダウンロードして展開します。

```bash
git clone https://github.com/maylabstudio-lab/amazon-search-filter.git
cd amazon-search-filter
```

### 2. Chromeに読み込む

1. Google Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
4. `manifest.json` が入っている `amazon-search-filter` フォルダを選択します。
5. 拡張機能一覧に「Amazon Search Filter」が表示されれば導入完了です。

## 使い方

### Amazonのページ内パネル（通常はこちら）

Amazon.co.jp を開くと、右下に折りたためる「正規品フィルタ」パネルが表示されます。

1. パネルのキーワード欄に入力して「検索」を押すと、設定を反映した検索結果ページへ移動します。
2. 「正規品に絞る」「『正規品』を検索語に追加」「カテゴリ」はその場で切り替えでき、
   非表示の切り替えは表示中の結果に即座に反映されます。
3. 検索結果ページでは、非表示にした件数と「すべて表示」ボタンがパネルに出ます。
4. パネル右上の「▾」で折りたたみ／展開できます。パネル自体を出したくない場合はポップアップの
   「Amazonのページに操作パネルを表示する」をオフにします。

### ポップアップ

1. Chromeのツールバーにある拡張機能アイコンから「Amazon Search Filter」を開きます。
2. 条件を指定し、キーワードを入力して「Amazonで検索する」をクリックします。
3. Amazon.co.jpの検索結果が新しいタブで開きます。

発送元・直販・割引率の指定はポップアップ側にあります。設定はポップアップとページ内パネルで共有されます。

## ソースを変更した場合

`chrome://extensions` の拡張機能一覧で「更新」ボタンをクリックすると、変更後のファイルが読み込まれます。

## 開発者への支援（Buy Me a Coffee）

ポップアップの「開発者を支援する」およびAmazonページのパネルのリンクからBuy Me a Coffeeのページを開きます。拡張機能はコード上でAPI連携をしておらず、リンクを開くだけです。実際に入金を受け取るには、Buy Me a Coffee 側で受取方法（銀行 / PayPal）を設定してください。支援先を変えるときは `popup.html` と `content.js` のURLを差し替えます。

## 一般公開（Chrome ウェブストア）

公開手順・収益化の注意（Amazonアソシエイトを有効化する前に確認すべき点）・パッケージング方法は [RELEASE.md](RELEASE.md) にまとめています。

- 提出用ZIP: `sh scripts/package.sh` → `dist/amazon-search-filter.zip`
- アイコン再生成: `icons/icon.svg` を編集して `sh scripts/make-icons.sh`

## ファイル構成

```text
amazon-search-filter/
├── manifest.json      # 拡張機能の定義（storage 権限・content script・アイコン）
├── popup.html         # ポップアップのUI
├── popup.js           # 検索URL生成・設定の保存/復元・タブ遷移
├── dictionary.js      # 辞書・商品名規約の判定・検索URL組み立て（popup と content で共有）
├── content.js         # ページ内パネル＋検索結果での出品の非表示・注意ラベル・件数表示
├── content.css        # content.js が注入する要素のスタイル
├── parametor.txt      # Amazon検索パラメータの定義（Amazon直販フィルタ）
├── icons/             # ストア用アイコン（icon.svg とそこから生成した PNG）
├── scripts/           # make-icons.sh / package.sh
├── RELEASE.md         # 公開チェックリスト
├── STORE_LISTING.md   # ストア掲載文案
├── PRIVACY_POLICY.md  # プライバシーポリシー
└── README.md          # 導入・利用手順
```

## 注意事項

- 現在の検索先はAmazon.co.jpです。
- v1 はAmazonアソシエイト（アフィリエイト）を利用していません。`dictionary.js` の `ASSOCIATE_TAG` は空です。有効化の前に [RELEASE.md](RELEASE.md) の注意を確認してください。
- Amazon側の仕様変更により、検索パラメータや検索結果ページのDOM構造が変わる場合があります。DOM変更時、`content.js` は出品の非表示・ラベル付けを止めますが、パネルやポップアップからの検索は引き続き動作します。
- この拡張機能は商品情報を収集・外部送信しません。選択した条件のみをChromeのストレージ（`chrome.storage.sync`）に保存します。
- 検索結果ページの警告ラベルは目安です。ラベルが付かない非正規品や、正規品に誤ってラベルが付く場合があります。
